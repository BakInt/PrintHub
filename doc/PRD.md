# PrintHub（云打印系统）PRD

本文描述云打印系统的产品目标、已实现能力、核心流程和后续演进方向。代码维护细节以仓库根目录 `AGENTS.md` 为准。

## 1. 产品定位

云打印系统面向小型门店、自助打印点、宿舍/园区共享打印场景。系统让用户在网页端上传文件、预览 PDF、查看价格、在线支付或使用账户余额支付；支付成功后，后端自动把文件下发到打印服务。

当前实现是可部署原型，重点覆盖完整业务闭环：

- 文件上传、转换、预览、安全检测。
- 游客支付打印和注册用户余额打印。
- 用户资料绑定、余额充值、订单查询。
- 管理后台、价格配置、促销配置、支付配置、打印机配置。
- CUPS 打印和跨平台系统打印基础支持（已移除 mock 模拟模式，均为真实打印）。

## 2. 目标用户和角色

### 2.1 游客用户

游客无需注册即可上传文件、查看价格并使用微信/支付宝付款打印。游客订单不绑定账户，适合临时使用。

### 2.2 注册用户

注册用户可以登录后维护姓名和手机号，使用账户余额支付，也可以在个人中心充值并查看最近订单。

### 2.3 管理员

管理员负责维护打印价格、安全阈值、促销规则、用户余额、订单状态、支付配置、打印机队列和异常告警。

## 3. 已实现功能范围

### 3.1 前台打印

- 支持 PDF、Office 文档和常见图片上传。
- Office 文档通过 LibreOffice 转 PDF，图片通过 Pillow 转 PDF。
- 上传后展示文件名、页数、文件大小、黑色覆盖率、安全状态和 PDF 预览。
- 只允许安全检测通过的文件参与计价和下单。
- 支持多文件一起下单。
- 支持单面/双面、彩色/黑白、份数、指定打印机、打印人姓名和手机号。
- 彩色/黑白与自动双面选项完全由后台配置的打印机属性（`is_support_color`、`is_support_auto_duplex`）驱动：打印机不支持时前台不展示对应选项，也不接受该选项的下单请求。
- 支持微信、支付宝、余额三种支付方式。
- 余额支付仅登录用户可用。

### 3.2 计价和促销

- 标准计价：单面按页计价，双面按纸张数计价。
- 按覆盖率计价：根据每页黑色覆盖率分档计算基础金额。
- 阶梯折扣：可配置满多少张打几折。
- 每日限时特价：可配置时间段、每日张数额度和折扣。
- 多个折扣同时命中时选择用户实际支付金额最低的方案。

### 3.3 账户和余额

- 用户名密码注册登录。
- 登录/注册需要验证码。
- 支持真实姓名和手机号绑定。
- 支持余额充值，充值通过易支付完成。
- 充值回调使用 `balance_applied_at` 防止重复入账。
- 余额支付后余额不能低于后台配置的最低余额。
- 支持兑换码充值：用户在个人中心输入后台生成的兑换码，按面额入账余额；兑换码可限制可用次数，有效期支持两种互斥方式二选一——「按有效天数」（填 0 表示永久有效）或「直接指定到期日期」（到期时间精确到所选日期的当天 23:59:59），也可限制每个登录用户的最大兑换次数（默认不限制，可自定义为任意正整数 N）。存量按天数设置的兑换码行为保持不变。

### 3.4 支付

- 支持易支付网关，网关地址通过配置指定（示例占位 `https://your-epay-gateway.example.com/submit.php`）。
- 支持支付宝 `alipay` 和微信 `wxpay`。
- 后端生成签名参数和自动提交 HTML 表单。
- 支付异步通知校验签名、订单号、金额和支付状态。
- 支持同步返回并跳回前端订单页或用户中心。
- 支付回调幂等，避免重复派发打印或重复充值。
- 后台支持测试支付单和模拟成功回调。

### 3.5 打印

- 已移除 mock 模拟模式，`cups`/`system` 均为真实打印。
- `cups` 模式（默认）通过 CUPS 命令创建队列、设置默认、启停、测试和下发打印任务。
- `system` 模式为跨平台真实打印入口：Linux/macOS 主要使用 CUPS，Windows 读取系统打印队列并尝试使用 SumatraPDF 或系统 PrintTo。
- 后台支持快速模板添加打印机，也支持高级 URI/驱动配置。
- 支持独立 CUPS Docker 打印服务，便于 Linux 服务器部署。
- 打印任务提交成功后进入 `printing`，后台监控会尝试确认完成或标记失败。

### 3.6 管理后台

- 概览：订单数、收入、待支付订单、打印失败数和未处理告警；统计卡片下方是「每日数据统计」图表模块，支持近 7 天 / 近 30 天切换（切换时实时刷新并显示加载状态）、订单趋势 / 收入趋势 / 打印失败分布三个维度 Tab、柱状图 + 折线图混合展示（柱表示数量、折线表示趋势，如订单趋势下柱为订单量、折线为收入）、可点击切换显示/隐藏的图例、hover 显示「日期 + 各系列数值」提示框、无数据时只显示友好空状态而不渲染空图表；纵轴标题为「数量」，横轴按日期；卡片底部注明「按本地时区统计每日订单与收入变化」。数据由后端按天聚合现有订单（按**本地时区**归日，返回订单数、收入、失败数），没有数据时同样返回完整日期序列。
- 订单：列表、详情、文件预览、标记完成、删除订单、删除未支付订单。
- 文件缓存：按时间段试算或清理上传缓存，可选择是否包含已关联订单文件。
- 用户：创建、编辑、启停、删除、余额增减和余额设置。
- 系统配置：计价模式、价格、折扣、限时特价、安全阈值、最大文件大小、最大页数和默认打印机。
- 支付配置：网关、商户 ID、商户密钥、公网回调地址、前端返回地址和配置校验。
- 打印机：列表、驱动列表与 PPD 上传、编辑、默认、启停、测试页、保存测试结果、删除。
- 兑换码：手动新增（兑换码可留空，留空由后端自动生成随机码，有效期可用「按天数 / 指定到期日期」分段按钮二选一，可设置「每个用户最大兑换次数」（开关 + 正整数，默认不限制））、批量生成随机码（有效期方式与手动新增一致）、删除兑换码。列表只保留兑换码、兑换面额、有效期、使用状态和操作五列，操作列固定在右侧始终可见；「有效期」列会写明天数或截止时间（指定日期模式显示到期时刻，永久有效显示「永久有效」）；点「详情」打开右侧详情抽屉，展示该兑换码的完整信息（完整兑换码、面额、已兑换次数、生成时间、有效期类型、有效期、单用户使用上限、累计可兑金额、使用状态）与已兑换用户列表。
- 告警：处理上传安全检测产生的异常告警。
- 手机端导航：后台功能仍集中在一个页面内，手机端改由固定在底部安全区之上的底部 Tab 栏承担导航（图标 + 文字、当前项高亮），常用项（概览 / 订单 / 用户 / 配置）常驻，其余项（支付 / 兑换码 / 备份 / 打印机）收进「更多」面板；切换行为与电脑端左侧菜单一致（同一个页面内切换视图，不跳路由）。电脑端保持原有左侧竖向菜单不变。概览「每日数据统计」的三个维度 Tab 在窄屏下可左右滑动查看并点击切换，位置不变。

### 3.7 亮色 / 深色主题

- 全站支持亮色（白天）与深色（暗夜）两种外观，前台所有页面与后台管理页面都跟随切换，不出现部分组件不生效。
- 支持手动切换（顶部导航的主题切换按钮）和自动判断：优先读取本地保存的选择，没有保存记录时跟随操作系统/浏览器主题偏好，并在系统主题变化时实时跟随。
- 用户的手动选择保存在浏览器本地（`localStorage` 键 `cloud-print-theme`），刷新、重开标签页都不丢失。
- 切换立即全局生效，不需要刷新页面；首屏由 `frontend/index.html` 的内联脚本提前写入主题标记，避免白屏闪烁。
- **电脑端和手机端是两套完全独立的配色方案**：按视口宽度（`max-width: 767px`，与手机端主断点一致）区分，两端各自拥有独立的亮色变量集与深色变量集，不使用同一套 CSS 同时控制两端。
- 两种主题、两种设备下，标题、正文、辅助文字、输入框、按钮、卡片、弹窗、表格、边框、滚动条、提示消息、分割线和阴影都重新配色，保证文字对比度充足、可读；深色模式下阴影和边框重新适配，不照搬亮色的投影颜色。
- 图片与图标在深色模式下通过 CSS 滤镜（`--cp-img-filter`）自动降低亮度，不刺眼；不修改任何图片文件；登录验证码图片单独用 `invert(1) hue-rotate(180deg)` 反色适配。
- 主题切换带平滑过渡动画（0.25s 颜色过渡），并在系统开启「减少动态效果」时自动关闭过渡。

## 4. 核心用户流程

### 4.1 游客打印

1. 用户进入首页。
2. 上传文件。
3. 系统转换 PDF、计算页数和黑色覆盖率。
4. 用户预览 PDF，选择单双面、彩色/黑白（打印机支持时）、份数、打印机和联系人。
5. 系统计算价格和折扣。
6. 用户选择微信或支付宝并创建订单。
7. 后端跳转易支付提交页。
8. 支付成功后回调后端。
9. 后端派发打印任务。
10. 用户在支付结果页查看订单状态。

### 4.2 注册用户余额打印

1. 用户注册或登录。
2. 在个人中心绑定姓名和手机号。
3. 上传文件并设置打印参数。
4. 选择余额支付。
5. 系统校验余额和最低余额要求。
6. 扣减余额并立即派发打印。
7. 用户查看订单状态。

### 4.3 用户充值

1. 用户进入个人中心。
2. 选择充值金额和支付方式。
3. 系统创建充值订单并跳转易支付。
4. 支付回调成功后增加余额。
5. 用户返回个人中心查看余额和充值订单。

### 4.4 管理员配置打印机

1. 管理员进入后台打印机页。
2. 选择快速添加模板或高级配置。
3. 填写 IP/主机名或 CUPS URI、驱动、位置和说明。
4. 保存打印机。
5. 发送测试页。
6. 管理员根据实际出纸结果确认成功、失败或部分成功。
7. 需要时设置为默认打印机。

## 5. 安全和风控要求

- 上传文件必须校验扩展名、文件大小、空文件和文件头签名。
- Office 转换失败、PDF 读取失败、页数超限或覆盖率超限时不能进入打印下单。
- 安全检测失败文件要保留记录并写入后台告警。
- 登录失败要隐藏具体原因，并按 IP + 用户名进行失败次数锁定。
- 生产环境必须更换应用密钥、管理员密码、支付商户信息和公网地址。
- 支付回调必须保留签名校验、金额校验和幂等处理。
- 文件缓存清理必须限制在上传根目录内，不能清理任意路径。
- 删除或停用管理员时必须保留至少一个可用管理员。

## 6. 运行和部署要求

### 6.1 开发和演示

- 默认使用 Docker Compose 启动。
- 打印方式由运行平台决定（`print_mode` 设置与 `PRINT_MODE` 环境变量已整体移除，所有打印均为真实打印，没有 mock 模拟模式）。开发/演示请指向测试用 CUPS 队列或备用打印机。
- 前端地址：`http://localhost:5173`。
- 后端地址：`http://localhost:8000`。

### 6.2 真实打印

- 仓库当前只提供单个 `docker-compose.yml`（单容器）；需要独立 CUPS 服务时，在后台「打印机」页或 `config.json` 的 CUPS 相关业务设置里指向可访问的 CUPS 地址（`cups_server`）。
- 网络打印机推荐使用固定 IP 和 IPP/AirPrint/Mopria。
- Windows v1 只管理系统已安装打印队列，PDF 打印建议配置 SumatraPDF。

### 6.3 生产部署

- 不再使用 `.env`：首次启动自动生成 `config/config.json`（含随机 `app_secret`），改完重启容器生效。
- 必须配置真实域名、HTTPS 公网回调地址、前端返回地址、易支付商户信息，并把 `environment` 改为 `production`（启动时会校验弱密码、占位支付信息等）。
- 数据库、上传文件、备份、日志和 `config.json` 都在宿主机 `./config` 绑定挂载目录里，需要定期整体备份。

## 7. 非目标和当前限制

- 暂未实现独立文档预览路由，预览嵌在首页和后台订单详情。
- 暂未实现订单取消退款流程。
- 暂未实现文件长期归档或对象存储。
- 暂未实现多门店、多租户和分账。
- 彩色/黑白与自动双面已实现，且完全由后台打印机属性驱动（打印机支持才展示、才允许下单）；暂未实现用户自助选择纸张规格、装订、横竖向等打印选项。
- Windows 平台下不能可靠自动确认真实出纸完成（已移除 mock 模拟模式）。
- 当前支付页是后端自动提交表单，不是直接展示二维码图片。

## 8. 后续可迭代方向

- 增加退款、取消订单和失败补打流程。
- 增加纸张规格、装订、横竖向等打印参数（彩色/黑白与自动双面已实现，见第 3.1 节）。
- 增加打印队列可视化和人工重试。
- 增加对象存储或周期归档策略。
- 增加更细的权限模型，例如运营、财务、设备管理员。
- 增加订单通知，例如短信、邮件或企业微信。
- 增加支付渠道抽象，降低易支付供应商耦合。
- 增加端到端测试，覆盖上传、支付模拟、充值和后台配置。
- 主题（亮/暗）目前只有手动切换和跟随系统，没有「定时切换」「跟随品牌色自定义」等更细的外观配置。

## 9. 核心验收口径

上线或较大版本变更前，至少应确认：

- 游客可以上传安全文件、预览、完成计价、创建易支付打印订单。
- 注册用户可以登录、绑定联系人、充值余额，并使用余额支付打印订单。
- 支付回调在签名正确且金额匹配时能更新订单；重复回调不会重复扣款、重复充值或重复派发打印。
- 安全检测失败、页数超限或文件转换失败的文件不能进入下单。
- 管理员可以查看订单详情、处理告警、调整价格/促销/支付/打印配置。
- 后台概览「每日数据统计」：近 7 天 / 近 30 天切换后图表数据变化且有加载状态；三个维度 Tab 展示对应数据；图例可点击切换系列显隐；hover 显示日期与数值提示框；无数据时显示空状态而非空图表；分日结果按本地时区归日（东八区下本地 00:00–08:00 的订单必须计入当天，而不是 UTC 的前一天）；小屏幕下图表、Tab 与按钮组不错位。
- 已移除 mock 模拟模式，`cups`/`system` 均为真实打印；真实打印联调前必须确认默认打印机、CUPS 地址和运行模式。
- 生产配置必须完成应用密钥、管理员密码、支付商户、域名和回调地址替换。
- 手机端后台导航：宽度 ≤767px 时顶部横向 Tab 条消失，改为固定底部的 Tab 栏（图标 + 文字、当前项高亮、位于安全区之上，不遮挡页面内容），常用项直接切换、其余项经「更多」面板切换，切换后内容与电脑端点同名菜单一致；电脑端（≥768px）仍为左侧竖向菜单，布局与此前一致。「每日数据统计」的三个维度 Tab 在窄屏下可左右滑动并点击切换，位置与桌面端一致，横向滑动不影响页面纵向滚动。
- 亮/暗主题：在电脑端与手机端分别检查亮色和深色四种组合，切换按钮立即生效且不刷新页面；刷新后主题保持；清除本地记录后跟随系统主题；深色模式下所有页面无浅底浅字、深底深字，图片不发白刺眼。
